# AS hub NEWs agent - 规则检查清单
# 每次生成报告前必须逐项检查

## 一、信息收集阶段检查

- [ ] **第一轮搜索**：使用通用关键词搜索（合成生物、合成生物学、synthetic biology等）
- [ ] **第二轮搜索**：使用 `site:` 限定符逐个搜索所有重点网站（6个国际+7个国内），以及深波synbio微信关键词搜索
- [ ] **第三轮搜索**：使用英文关键词补充搜索（synthetic biology, biomanufacturing, precision fermentation, cell factory等）
- [ ] **第四轮搜索**：检查今日/本周是否有遗漏，重点查看投资界、36氪、动脉网、科技日报、深波synbio、iGEM等高频更新源
- [ ] **第五轮搜索**：政府与学术会议定向搜索（北京市科委、深圳市科创委、上海市经信委、科学网、AIChE/SBE会议等）
- [ ] 每条信息记录了来源网站和发布日期
- [ ] 优先选择了有明确时间戳的信息
- [ ] 补充搜索覆盖了英文关键词（synthetic biology, biomanufacturing, precision fermentation等）

### ⚠️ 信息源遗漏陷阱（必须避免）

**陷阱1：只搜通用关键词，遗漏 site: 定向搜索**
- 后果：错过投资界、36氪、动脉网等垂直媒体的独家信息
- 对策：必须执行第二轮 `site:` 限定符搜索

**陷阱2：只搜一次，不检查是否有新信息发布**
- 后果：上午搜索后，下午发布的新信息被遗漏
- 对策：报告生成前必须执行第四轮复查，确认无新信息遗漏

**陷阱3：只搜中文，不搜英文**
- 后果：错过SynBioBeta、GEN、FierceBiotech、iGEM等国际源的重要动态
- 对策：必须执行第三轮英文关键词补充搜索，第二轮必须搜索iGEM官网

**陷阱4：遗漏微信公众号源**
- 后果：错过深波synbio等微信独家内容
- 对策：第二轮必须执行`深波synbio 合成生物`等关键词搜索

**陷阱5：遗漏政府官网和学术会议网站**
- 后果：错过科委征集通知、会议征文等关键信息
- 对策：必须执行第五轮政府与会议定向搜索

## 二、时效性检查

- [ ] 行业新闻：发布日期在7天内
- [ ] 融资动态：发布日期在7天内
- [ ] 研究成果：发布日期在14天内（重大成果可放宽至30天）
- [ ] 政策监管：发布日期在30天内
- [ ] 行业活动：举办日期在未来90天内
- [ ] 超过时间窗口的信息已排除

## 三、去重检查

- [ ] 已读取最近7天的历史报告
- [ ] 已对比历史事件指纹库
- [ ] 同一公司+同一事件类型的信息未重复收录
- [ ] 同一产品+同一里程碑的信息未重复收录
- [ ] 同一政策+同一发布机构的信息未重复收录
- [ ] 同一论文+同一期刊的信息未重复收录
- [ ] 已收录政策已查重（对比policy_database.json）
- [ ] 同一事件的多源报道已聚合为一条

## 四、价值排序检查

- [ ] 信息已按价值分数排序
- [ ] 执行摘要精选了5条最有价值的信息
- [ ] 重大融资/并购优先收录
- [ ] 政策发布/法规更新优先收录
- [ ] 顶级期刊论文优先收录
- [ ] 来源权威性已评估（Nature/Science > 行业媒体 > 自媒体）

## 五、格式检查

- [ ] 报告严格使用模板结构
- [ ] 行业热点新闻 = Markdown表格（标题|来源|时间|摘要|链接）
- [ ] 最新研究成果 = Markdown表格（标题|期刊/机构|核心发现|链接）
- [ ] 融资与投资动态 = Markdown表格（公司|轮次|金额|投资方|链接）
- [ ] 政策与监管 = 国内政策表格 + 国际动态列表
- [ ] 行业活动预告 = Markdown表格（活动名称|时间|地点|亮点|链接）
- [ ] AI深度分析 = 趋势研判 + 竞争格局 + 风险提示
- [ ] 无额外板块（如"公司/产品进展"等）
- [ ] 附录包含完整链接列表

## 六、内容质量检查

- [ ] 执行摘要每条包含核心事实
- [ ] 摘要按价值从高到低排序
- [ ] AI深度分析基于当日/当周信息
- [ ] 趋势判断引用具体事件作为论据
- [ ] 三维度交叉分析：政策 + 科研 + 行业
- [ ] 预测未来1-4周发展，标注置信度
- [ ] 无空泛套话（如"行业前景广阔"）
- [ ] 竞争格局分梯队描述
- [ ] 风险提示具体且有依据

## 七、邮件发送前最终检查

- [ ] Markdown报告已保存到reports目录
- [ ] H5 HTML报告已保存到reports目录
- [ ] **邮件附件MIME类型正确**：
  - [ ] HTML附件使用 `MIMEText(html_content, 'html', 'utf-8')` → MIME类型: `text/html`
  - [ ] Markdown附件使用 `MIMEText(md_content, 'plain', 'utf-8')` → MIME类型: `text/plain`
  - [ ] **严禁使用 `MIMEBase('application', 'octet-stream')` 发送附件**（会导致附件变成.bin文件）
- [ ] HTML报告作为邮件附件
- [ ] 邮件主题正确：合成生物行业日报 — YYYY年MM月DD日
- [ ] 收件人正确：197286184@qq.com
- [ ] 邮件正文包含执行摘要+精选内容+深度分析

### ⚠️ 邮件附件MIME类型陷阱（必须避免）

**陷阱：使用 `MIMEBase('application', 'octet-stream')` 发送HTML/MD附件**
- 后果：QQ邮箱等客户端无法识别文件类型，附件显示为 `.bin` 文件或 `application/octet-stream`
- 对策：HTML附件必须用 `MIMEText(content, 'html', 'utf-8')`，MD附件必须用 `MIMEText(content, 'plain', 'utf-8')`

- [ ] 脚本验证报告结构通过
- [ ] 脚本验证时效性通过
- [ ] 脚本验证无重复信息
- [ ] 综合评分 >= 80分
- [ ] 无必须修复的错误
- [ ] 如有警告，已评估是否影响发送
